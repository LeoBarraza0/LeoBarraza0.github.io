# leobarraza0.github.io

Mi portafolio: **https://leobarraza0.github.io** · en inglés: `?lang=en`

HTML, CSS y JavaScript sin frameworks ni paso de build. GitHub Pages lo sirve desde `main`.

- `index.html`: el contenido. Cada texto existe dos veces, con `lang="es"` y `lang="en"`, y el CSS muestra el del idioma activo.
- `styles.css`: los estilos.
- `main.js`: la terminal interactiva, el cambio de idioma, el git graph de la trayectoria y el último push leído de la API de GitHub.
- `cv/`: la HV (ES) y el Resume (EN) en PDF. Son copias: reemplazarlas cuando cambie la HV.

En local basta con abrir `index.html`.
