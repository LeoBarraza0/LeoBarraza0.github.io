Conversor PDF → TIF con OCRPDF → TIF converter with OCR

en producciónin production

Reemplazó un proceso manual. Recibe lotes de PDF escaneados, los convierte a TIF, lee cada página con OCR y archiva cada documento en la carpeta de la persona según el número de cédula que encuentra. Cada lote termina con un reporte CSV para auditoría.

It replaced a manual process. It takes batches of scanned PDFs, converts them to TIF, runs OCR on every page and files each document under the ID number it finds. Every batch ends with a CSV audit report.

Sistema de inventario tecnológicoIT-inventory system

en construcciónin development

La Secretaría levanta el inventario de sus colegios por tres canales con formatos que no se pueden cruzar. Diseño una base única de la que salen todos los reportes y la aplicación web con la que cada sede registra lo que tiene. Los colegios no tienen cuenta institucional de Google, así que cada sede entra con su propio enlace con token, sin usuario ni contraseña.

The Secretariat collects its schools' IT inventory through three channels whose formats can't be reconciled. I'm designing a single database that every report comes from, and the web app each school site uses to register its equipment. Schools have no institutional Google accounts, so each site signs in through its own token link, with no username or password.
